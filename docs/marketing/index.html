The last two rows are the ones worth arguing about. A rolling-vintage score is labeled as one rather than presented as a clean year-over-year series, and a suppressed measure stays suppressed instead of being coerced into a number. A screening verdict is Excluded, Clear or Unverified; an identity that could not be checked is never reported as clear.

The work was reviewed, adversarially

Two review documents ship with the platform and are available on request. Excerpts below are headers and scope statements; the findings themselves, open and closed, stay with the code.

Code review, analytics service

"Adversarial Code Review: Provider Intelligence Platform Analytics Service"

"Findings are ordered by severity. Where the provided materials were insufficient to judge a concern, that is stated explicitly."

A line-by-line review of the statistics code, hunting for the failure that matters most here: a confident wrong number. The critical findings were about null handling, rankings and rolling-vintage year labels, and they are closed. Each one has a regression test.

Security review, PHI posture

"The platform currently serves only public US government data. No patient data, no user account data, no claims data is present."

"Because protected data is a plausible future state, the auth, logging, and encryption gaps should be fixed before the feature that introduces protected data ships, not after."

A written hardening backlog, ordered by priority, with the HIPAA obligations that would attach the moment protected data entered the system. The current answer is that none has, and the engagement gates below keep it that way.

Data and compliance

Built entirely on public CMS and NIH data. No PHI handled. BAA available for scoped engagements.

Engagements are public-data-only by default, so no Business Associate Agreement is triggered. If a scope would require receiving protected health information, the BAA is signed first, before any data moves.

Screening output is a diligence aid compiled from public sources. It is not legal advice and is not a consumer report. Screening used for credentialing, employment or other eligibility decisions may implicate the Fair Credit Reporting Act and state screening laws; applicability is confirmed before any output is sold into those use cases.

Every report carries this sentence, verbatim: this report states what public sources published as of the dates shown. It does not certify any provider's status.
